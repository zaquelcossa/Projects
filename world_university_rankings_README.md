# World University Rankings Analysis

This project analyzes global university rankings across 2,200+ institutions using datasets from Times Higher Education, the Shanghai Ranking, and the Center for World University Rankings. The project focuses on comparative analysis and data visualization using Python libraries including Pandas, Matplotlib, and Seaborn.

Key insights were derived from:
- Country-level average score comparisons
- A breakdown of the top 10 U.S. universities
- A boxplot showing score distributions by country
- A scatterplot exploring the relationship between research publications and institutional score (2012–2015)

This analysis highlights patterns in global higher education, research output, and institutional performance.

**Tools Used:** Python, Pandas, Seaborn, Matplotlib, Jupyter Notebook
